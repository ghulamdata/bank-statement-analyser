# Bank Statement Analyser

## Overview

A Python application that extracts transactions from PDF bank statements, cleans and categorises financial data, and stores it in PostgreSQL. An interactive Streamlit dashboard displays income, spending and cash flow.

## Technologies Used

- Python
- Pandas
- PyMuPDF
- PostgreSQL
- Psycopg
- Streamlit
- Plotly

## Features

- Extract and clean transactions from Halifax PDF statements.
- Automatically categorise transactions.
- Store data in PostgreSQL and prevent duplicate imports.
- Visualise income, outgoing payments and cash flow.
- Filter reports by month or custom date range.
